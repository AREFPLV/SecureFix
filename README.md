# SecureFix

Vite + React site for SECUREFIX LTD, 218 City Road, London EC1V 2PN.

```bash
npm install
npm run lint
npm run build
```

The build prerenders an HTML file for every indexable route and writes `sitemap.xml`. After deploy, submit `https://securefix.uk/sitemap.xml` in Google Search Console and request indexing for these ten repair URLs:
